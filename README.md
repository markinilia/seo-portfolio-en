# English SEO Portfolio — Ilia Markin

Static, responsive GitHub Pages portfolio. Includes 13 SEO case studies and locally bundled cover images.

## Publish
Upload `index.html` and the `images/` folder to the root of your GitHub Pages repository. GitHub Pages will serve the site automatically when enabled for the branch.

The case study links point to the Google Docs URLs supplied in `SEO cases in eng.docx`; their access permissions are managed separately in Google Drive.
